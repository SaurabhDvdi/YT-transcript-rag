# Product Specification & Architecture (Phase 11)

## 1. Product Overview

The **YouTube AI Assistant** is a browser extension that enables viewers to understand any supported YouTube video, ask detailed questions, and verify AI responses directly against timestamped source citations in the original video.

### Core Value Proposition

> **"Understand any supported YouTube video, ask questions about it, and verify answers against the original video."**

---

## 2. Product Principles

1. **Trust Through Verifiability (Grounding First)**
   - Answers are never presented in isolation. Every claim generated by the grounded retrieval engine is backed by verifiable transcript chunks with timestamp boundaries.
   - Users can click on any citation chip to immediately seek the YouTube video player to that exact moment.
2. **Speed & Ergonomic Responsiveness**
   - Live Server-Sent Events (SSE) token streaming provides immediate feedback with a blinking cursor and a one-click Stop Generation control.
   - Quick Actions ("Summarize", "Key Points", "Explain Simply") provide single-click answers for common workflows.
3. **Compact Sidepanel Ergonomics**
   - Designed specifically for standard browser sidepanel widths (360px to 480px).
   - Uses concise information hierarchy, clamped multi-line headings, and collapsible metadata to preserve chat real estate.
4. **Privacy & Respect for Boundaries**
   - Operates strictly on `youtube.com/watch*` URLs.
   - User identity, tokens, and conversations are strictly isolated and never exposed to page scripts.
   - Supports anonymous sessions with seamless session migration upon sign-in.

## 3. Feature Breakdown

### 3.1 Video Detection & Card

- Automatic video detection via URL observer in the extension content script.
- Displays video thumbnail (with fallback placeholder), video title (2-line clamp with full tooltip), and video duration.
- Visual status badges indicate whether the transcript has been extracted and whether the grounded retrieval index is ready.
- Quick link action to copy the clean canonical YouTube link.

### 3.2 Quick Action Prompts

- Grounded one-click prompts pinned at the bottom of the conversation:
  - **Summarize**: Concise high-level summary of main topics.
  - **Key Points**: Structured bullet points of core arguments and facts.
  - **Explain Simply**: Beginner-friendly explanations free of unnecessary jargon.
- Automatically disabled during generation to prevent race conditions.

### 3.3 Streaming Conversational Q&A

- **Real-Time Token Streaming**: Server-Sent Events (SSE) render responses token-by-token.
- **Stop Generation**: Users can cancel long-running streams at any time via an abort controller.
- **Retry Mechanism**: Transient failures or network hiccups can be retried with a single click.
- **Keyboard Shortcuts**: `Ctrl + Enter` (or `Cmd + Enter`) sends questions instantly; `Esc` closes modals and drawers.

### 3.4 Interactive Timestamp Citations & Seeking

- **Interactive Badges**: Citations display formatted timestamps (`MM:SS` or `H:MM:SS`).
- **Active Seeking**: Clicking a citation chip sends a `SEEK_VIDEO` extension message to the content script running on the YouTube tab, updating the video player's `currentTime` and resuming playback.
- **Verified Evidence Tooltips**: Hovering or focusing on a citation displays the exact snippet quoted from the video transcript.
- **Clean Copying**: Copying an assistant message automatically converts `[E1]` citation tokens into clean timestamps (`[01:15–01:30]`) and appends a verified sources breakdown.

### 3.5 Conversation Drawer & Management

- **Drawer Overlay**: Slide-over panel listing all past chat threads for the active video.
- **Client-Side Search**: Instant title filtering as the user types in the search bar.
- **Title Editing**: In-place renaming with double-click or edit icon.
- **Safe Deletion**: Accessible modal confirmation dialog (`role="alertdialog"`) with `Cancel` as default focus to prevent accidental data loss.
- **Markdown Export**: One-click download of the complete chat transcript formatted in clean Markdown.

### 3.6 Theme System

- Complete theme engine supporting **Light**, **Dark**, and **System Default** modes.
- Persistent across browser sessions via `chrome.storage.local`.
- Synchronized with OS `prefers-color-scheme` media queries when set to System.

---

## 4. Product Non-Goals

To maintain strict architectural discipline and enterprise release readiness, the following capabilities are explicitly out of scope:

- **No global cross-video memory or cross-video synthesis.** Conversations are scoped to specific YouTube videos.
- **No autonomous agents or web browsing.** The assistant answers questions strictly from the video's transcript and metadata.
- **No audio/video transcription from raw media.** Transcripts are fetched via existing backend retrieval endpoints.
- **No voice input/output or speech synthesis.**
- **No public link sharing or third-party tracking scripts.**
- **No backend redesign.** The established FastAPI, Cloudflare Workers, D1, and KV stack remains frozen.
